# aigc-lite v0.4.1 release closure

**Status:** frozen source patch baseline

**Date:** 2026-09-29

**Package version:** `0.4.1`

**Git anchor:** annotated tag `v0.4.1`

This patch retains the `v0.4.0` feature boundary while closing issues found by
release smoke tests and independent pull-request review. The historical
`v0.4.0` tag remains unchanged.

## Patch scope

- generate independent valid authentication and encryption secrets in the
  hardened container smoke;
- require and atomically consume a current Qualification-backed
  `AuthorizationGrant` before ROS 2 physical actions reach their provider;
- bind physical authority to the authenticated actor, native action, host-owned
  provider identity, and bridge robot identity;
- exclude expired, exhausted, stale, and superseded grants from execution and
  portable Assurance Bundle authority;
- recursively propagate dependency staleness, terminate cycles safely, and
  normalize duplicate dependency edges;
- select a policy-valid kernel certificate when older invalid verification
  artifacts coexist with a newer valid result;
- preserve the existing default model flag during encrypted-credential rebinding.

## Verified patch

The merged patch was verified with:

- 161 passing tests and one environment-conditional skip;
- Ruff and Python byte compilation;
- a live PostgreSQL migration/repository contract including atomic grant
  consumption;
- frontend build, production dependency audit, and packaged static-asset sync;
- clean-install core and ROS 2 simulator wheel smokes;
- hardened Docker build/startup, `/ready`, and packaged React UI smoke;
- successful GitHub push and pull-request CI matrices.

## Unchanged non-claims

This source tag does not claim a PyPI publication, container registry digest,
SBOM attestation, hosted deployment, penetration test, or real Nav2/Gazebo/
hardware acceptance. Simulator acceptance remains separate from physical robot
safety acceptance. Any binary or container publication must be built from this
tag and retain its own digest and supply-chain evidence.
