# aigc-lite v0.4.0 release closure

**Status:** locally frozen source baseline

**Date:** 2026-09-29

**Package version:** `0.4.0`

**Git anchor:** annotated tag `v0.4.0`

This record defines the source and validation boundary of `v0.4.0`. The tag
anchors committed source; it does not claim a container registry digest, PyPI
publication, hosted deployment, or physical-system acceptance.

## Release scope

- portable Assurance Bundles and offline verification;
- Qualification Plane, domain verifier profiles, evidence closures,
  deterministic gates, qualification receipts, current-use bindings, and
  authorization grants;
- real Lean 4 and Coq kernel process backends with bounded execution and
  explicit non-sandbox limitations;
- independently packaged ROS 2 capability bridge with deterministic simulator
  and lazy Nav2 adapter;
- workspace credential boundary hardening for MCP and custom model routes;
- non-loopback startup guard and loopback-only Compose publication;
- separate liveness and fail-closed database/migration/scheduler readiness;
- canonical React UI bundled in the Python wheel and Docker image.

## Locally verified release

The following checks were performed from the release source on 2026-09-29:

- core wheel built, installed outside the checkout, and served `/ui/` plus its
  hashed React asset. The final post-split repeat used a new venv with
  preinstalled dependencies because direct PyPI resolution hit a local TLS
  error; a clean dependency-resolving install had passed earlier in the same
  candidate cycle;
- ROS 2 bridge wheel built and passed deterministic simulator state/navigation
  receipt smoke outside the checkout;
- Docker image built; a hardened container passed `/ready` and served the React UI;
  an insecure non-loopback container refused startup;
- PostgreSQL 17 migrated through `0013_model_credential_binding` and passed the
  repository contract for workspace credentials, model/MCP binding, and Runs;
- frontend clean install/build completed and production dependency audit
  reported zero vulnerabilities;
- full backend/extension suite: 158 passed, 1 environment-conditional test
  skipped; Ruff and Python byte compilation passed.

## Explicit non-claims

- Simulator acceptance is not Gazebo, Nav2, DDS, hardware, real-time, or robot
  safety acceptance. No real Nav2/Gazebo/hardware acceptance is claimed here.
- M8ven or another external source-code badge is not a Qualification Plane
  receipt and does not grant execution or publication authority.
- Kernel acceptance verifies the submitted formal artifact under the recorded
  toolchain/assumption closure; it does not establish informal semantic
  alignment by itself and the host process is not a security sandbox.
- No container registry digest, SBOM attestation, PyPI publication, hosted
  deployment, independent penetration test, or scientific review is claimed.
- PostgreSQL contract coverage is single-worker. Distributed scheduler leasing
  and multi-worker delivery have not been accepted.

## Release boundary

Before creating the annotated `v0.4.0` source tag, the release process:

1. ran the full tests, Ruff, byte compilation, dependency audits, both
   clean-install wheel smokes, PostgreSQL contract, and Docker startup smokes;
2. verified the public tree contains no `.env`, database, key, token, local proxy,
   private hostname, or generated runtime evidence;
3. aligned Python, ROS 2, frontend, FastAPI/MCP metadata, changelog, and this
   record at `0.4.0`;
4. created a dedicated release commit followed by the immutable annotated tag.

No binary package or container image is published by this source tag. Any later
publication must be built from the tag, repeat its artifact smoke tests, and
retain an SBOM plus the package or image digest at that publication boundary.
