# aigc-lite v0.2.0 release acceptance

**Status:** locally frozen source baseline

**Date:** 2026-09-24

**Release kind:** initial repository baseline

**Git anchor:** annotated tag `v0.2.0`

This record applies the useful parts of the `rime-lite` release discipline to a
software service: the release identity, validation evidence, and future work are
kept separate. The tag anchors only the committed paths; it does not claim a
remote publication, signed tag, container digest, PyPI artifact, or independent
security review.

## Release identity

The release consists of the tracked source tree at `v0.2.0`, including backend,
frontend, migrations, tests, deployment examples, public documentation, MIT
license, and CI workflow. Generated wheels, frontend bundles, databases, local
environment files, caches, logs, IDE state, and runtime data are excluded.

Version-bearing surfaces are aligned at `0.2.0`:

- Python project metadata;
- FastAPI application metadata;
- frontend package and lock file.

## Validation profile

The accepted candidate must pass from the repository root:

```text
pytest -q
ruff check app tests
python -m compileall -q app
npm ci                         (frontend/)
npm run build                  (frontend/)
python -m pip_audit . --progress-spinner off
npm audit --omit=dev --audit-level=high  (frontend/)
python -m pip wheel . --no-deps --wheel-dir .tmp-wheel
```

The wheel inventory must contain the packaged Alembic environment and must be
able to initialize a new SQLite database outside the source checkout. Release
verification must not change tracked files.

Accepted local results on 2026-09-24:

- backend: 54 tests passed; Ruff and byte-compilation passed;
- frontend: production build passed; npm audit reported 0 vulnerabilities;
- Python dependency audit: no known vulnerabilities reported;
- secret-pattern scan: no credential-shaped values found outside documented
  placeholders and tests;
- wheel smoke test: installed `aigc-lite 0.2.0` initialized a fresh database at
  Alembic revision `0002_mcp_probe_state` using only packaged migration files.

## Known boundaries

- SQLite is intended for a single-process quick start; PostgreSQL contract CI
  is not yet present.
- Remote URL validation is not yet a complete SSRF defense.
- API-key scopes, service accounts, Run events/budgets, encrypted credential
  references, Artifact/Citation, FTS, and master-key rotation remain future
  work and are not implied by this tag.
- The hand-written `/mcp-legacy` endpoint is compatibility-only; the official
  SDK transports are `/mcp` and `/mcp-sse/sse`.
