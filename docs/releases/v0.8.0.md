## Upgrade, rollback, and authority boundary

Before upgrading a deployment, stop writers and new external dispatch,
inventory pending/indeterminate operations, and verify a database backup
outside the working tree. Rehearse on a copy. The schema transition is
`0025_invocation_timeout` → `0029_shared_attempt_invalidation`; new proof
selection indexing preserves historical Receipts and conservatively blocks
current use when an old mathematical selection cannot be reconstructed.
Do not retry unresolved external operations merely because migration
completed. After new writes, rollback requires stopping the new runtime,
restoring the pre-upgrade database backup, and reconciling external side
effects; an in-place Alembic downgrade is not a lossless rollback.

Native Goal Binding records goal identity, while Goal Progress Evidence
Bridge v0.1 is a read-only conditional diagnosis. Its `UNRESOLVED` result
for missing proof selection is distinct from the authoritative Qualification
path that blocks current use and Grant consumption. Neither a bound Goal nor
a progress result qualifies domain evidence or authorizes recovery. Model
output still cannot directly mutate qualification, current knowledge use,
or execution authority.

Math Project 003 lacks complete Comparator/kernel replay and statement
alignment acceptance. Bio/Citation source authenticity and their MDE
conclusions remain bounded research Cases. ROS 2 simulator acceptance is
not live Nav2/Gazebo or physical-hardware acceptance. The core does not
provide complete OS isolation for arbitrary untrusted Agent code or a
cross-Run RootBudget. These incomplete research and infrastructure tasks
did not block this engineering release and are not silently certified by it.
