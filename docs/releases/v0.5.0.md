# aigc-lite v0.5.0 release closure

**Status:** frozen source feature baseline

**Date:** 2026-09-30

**Package version:** `0.5.0`

**Git anchor:** annotated tag `v0.5.0`

This release turns the execution-memory and Qualification foundations into a
more directly usable AI workbench while preserving the separation between
stored candidates, epistemic qualification, current-use binding, and execution
authority.

## Release scope

- expose bounded workspace read capabilities through the default MCP Tool
  Catalog without duplicating application services;
- add deterministic Review Profiles and immutable ReviewRun/ReviewFinding
  records, starting with `execution.integrity.v1`;
- make chat capability selection server-owned, read-only by default, and
  explicitly authorization-gated for delegated or side-effecting work;
- import ChatGPT and DeepSeek conversation exports through preview, immutable
  atomic ImportBatch commit, content-addressed source Artifacts, and
  candidate-only search projection;
- close reviewed authorization, transitive-staleness, and Nav2 dispatch/
  indeterminate-motion races;
- document a threat model that assumes the governed Agent may understand its
  gates while remaining unable to change their authority;
- add immutable `PolicyProposal`, conservative server-derived
  `PermissionDiff`, and backend-issued `EnforcementReceipt` contracts as the
  evidence seam for a future out-of-process enforcer;
- continue the architecture split with injected research routers and explicit
  Research/Qualification repository ports and adapters.

`PolicyProposal` in this baseline is proposal-only. It cannot approve or apply
policy. `EnforcementReceipt` has no public write endpoint, and an external
signature or attestation is recorded as evidence rather than treated as
verified authority.

  sensitive candidates.

## Migration note

Alembic head is `0017_execution_authority`. Development databases briefly
created with the unreleased, PostgreSQL-incompatible provisional revision name
are relabeled automatically on SQLite without deleting application data.

## Unchanged non-claims

This source tag does not claim PyPI or container-registry publication, an SBOM
or signed supply-chain attestation, hosted deployment, penetration testing,
external-enforcer integration, DPU/hardware isolation, or real Nav2/Gazebo/
robot acceptance. The ROS 2 simulator remains test evidence, not physical
safety qualification. Artifact signatures and external attestation evidence
remain unverified until a separately trusted verification path is implemented.
